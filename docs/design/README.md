# デザインの参照資料

Claude Design で用意したデザインの取り込み先。コードではなく、画面を作るときに見る参照資料として置く（[D-0017](../decisions/D-0017-design-import.md)）。

## 置き場

| ファイル | 中身 |
|---|---|
| `ios/merb iOS.dc.html` | 画面の一覧（ホーム 2e、分類を選ぶ 2f、設定 2g、出題の4つの状態 2a から 2d） |
| `ios/MerbQuiz2.dc.html` | 出題の画面の部品。状態は `phase` で切り替える |
| `ios/ios-frame.jsx` | iOS の端末枠。デザインの見せ方のためのもので、アプリには要らない |
| `ios/support.js` | `.dc.html` を表示する Claude Design の実行環境。生成物なので書き換えない |

- 取り込み元は Claude Design のプロジェクト `712f28b7-b985-44d1-8dd2-090a06a6cce4`。内容は読み取ったまま保存している。
- 数式は KaTeX 0.16.11 の CDN から読む。`.dc.html` は `support.js` と同じフォルダに置いて、ブラウザーで開く。
- Lint、型検査、テストの対象ではない。

### 取り込まない

| デザイン | 理由 |
|---|---|
| 端末の枠（ステータスバー、ダイナミックアイランド、ホームインジケーター）。`ios-frame.jsx` | デザインの見せ方のためのもの。実機では OS が出す |
| 「次の一手」の欄（ダークモード追加などの案） | デザインの作業メモで、画面の一部ではない |
| ダークモード | デザインに画面がない。範囲外 |
| デザインの `x-dc` や `sc-for` などの記法 | Claude Design の表示用。アプリでは React Native で書き直す |

## `vision.md` に照らした確認

- 「やらないこと」: アカウント、学習の記録の保存と同期、進捗の管理、ゲーム性に当たる要素は見つからなかった。正解数、連続正解、点数、記録の画面はない。
- 判断の基準の2つ目（画面がシンプルであること）: キャッチフレーズ、説明文、飾りの文言は見つからなかった。出題の画面の問題文は D-0011 の例外に当たる。ホームの「merb」はアプリの名前で、キャッチフレーズではない。
- ボタンの文言「問題を解く」「選んだ分類で始める」「すべての分類から出す」は、`category-select.md` と `quiz.md` の文言と同じ。
- 正解と不正解は、色だけでなく「正解」「不正解」の文字と印でも示している。
