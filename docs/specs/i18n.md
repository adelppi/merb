# 画面の文言の言語の切り替え

- 状態: 実装済み
- Issue: #15、#37、#56
- 関係する決定: [D-0006](../decisions/D-0006-locale-storage.md)、[D-0012](../decisions/D-0012-native-app.md)、[D-0018](../decisions/D-0018-design-open-questions.md)、[D-0019](../decisions/D-0019-i18n-and-locale-storage.md)、[D-0024](../decisions/D-0024-native-header-home.md)
- デザイン: [docs/design/](../design/README.md) のホーム（2e）と設定（2g）

## 目的

`vision.md` の「やること」にある「画面の文言は日本語と英語に対応する」に当たる。利用者が、画面の文言を日本語と英語から選べるようにする。

## 振る舞い

1. 画面の文言は、日本語と英語の2つから出す。
2. 言語を保存していないときは、日本語で出す。端末の言語の設定には合わせない。
3. 設定画面（`/settings`）で、日本語か英語を選べる。選んだ言語は、端末に保存する。
4. 言語を選ぶと、設定画面を開いたまま、画面の文言がその言語に変わる。
5. アプリを開いたとき、端末に保存した言語を読み、その言語で文言を出す。読み終えるまでは、画面を出さない。
6. 保存した言語を読めないときや、保存した値が日本語か英語のどちらでもないときは、日本語で出す。保存できないときは、選んだ言語をアプリを閉じるまで使う。
7. ホーム（`/`）は、Stack のヘッダーに大見出し「merb」（iOS 純正の大タイトルで、ヘッダーの背景は透明にする）を出し、ヘッダーの右上に、設定画面を開く歯車のボタンを置く。歯車はアイコンだけなので、読み上げ用の名前に「設定」（英語では「Settings」）を付ける。設定画面の左上には戻るボタンを置く。ほかの画面には、言語を切り替えるボタンを置かない（[D-0024](../decisions/D-0024-native-header-home.md)）。
8. 設定画面は、大見出し（「設定」。iOS 純正の大タイトルで、ヘッダーの背景は透明にする）、節の名前（「言語」）、言語の行の一覧で作る。行の名前は、選んでいる言語によらず、それぞれの言語で書く（「日本語」「English」）。いま選んでいる言語の行の右端に、チェックを付ける。行をタップすると、その言語に切り替わる。
9. ボタンの背景は、iOS 26 以上では Liquid Glass で出す。それより前の iOS では、通常の半透明の背景で出す（[D-0018](../decisions/D-0018-design-open-questions.md)）。ホームの「問題を解く」は、iOS 26 以上では藍に色付けした Liquid Glass、それより前は藍の背景で出す（[D-0027](../decisions/D-0027-prominent-glass.md)）。ホームの歯車はヘッダーのネイティブのボタンなので、この切り替えは OS が行う。アイコンは SF Symbols を使う。

文言のファイルは、言語ごとに `src/i18n/messages/ja.json` と `src/i18n/messages/en.json` に置く。2つのファイルは同じキーを持つ。

保存先は `@react-native-async-storage/async-storage`。キーは `merb.locale`、値は `ja` か `en` にする。

## 受け入れ条件

この条件をすべて満たせば実装済みとする。テストはこの条件と対応させる。

- [x] 言語を保存していないとき、ホームが日本語の文言で出る（単体テスト: 保存がなければ `ja`）
- [x] 設定画面で English をタップすると、設定画面の文言が英語になり、English の行にチェックが付く
- [x] English を選んだあと、アプリを開き直すと、英語の文言で出る（単体テスト: 保存と読み出し）
- [x] English を選んだあと日本語を選ぶと、日本語の文言に戻る
- [x] 保存した値が `ja` と `en` のどちらでもないとき、または読めないとき、日本語で出す（単体テスト）
- [x] 保存できないとき、選んだ言語をアプリを閉じるまで使う（単体テスト: 保存の失敗で例外を出さない）
- [x] 日本語と英語の文言のファイルが同じキーを持つことを、単体テストで確かめる
- [x] ホームの歯車に、読み上げ用の名前が付いている

画面の表示と操作は、単体テストの対象ではない。操作テストの道具は Maestro で、手元から実行する（[D-0021](../decisions/D-0021-operation-test-tool.md)）。

## 範囲外

この仕様で扱わないこと。

- 出題の画面と、分類を選ぶ画面
- 問題の JSON の中身の翻訳。問題の読み方は英語のまま。問題文は、問題の JSON に日本語と英語の両方を書く（[問題の JSON の形](question-format.md)の「問題文」の節）
- 端末の言語の設定から言語を選ぶこと
- 端末をまたいで言語の設定をそろえること
- ダークモード（デザインに画面がない）
