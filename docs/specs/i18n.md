# 画面の文言の言語の切り替え

- 状態: 合意
- Issue: #15
- 関係する決定: [D-0003](../decisions/D-0003-tech-stack.md)、[D-0006](../decisions/D-0006-locale-storage.md)

## 目的

`vision.md` の「やること」にある「画面の文言は日本語と英語に対応する」に当たる。利用者が、画面の文言を日本語と英語から選べるようにする。

## 振る舞い

1. 画面の文言は、日本語と英語の2つから出す。言語は URL に含めない。
2. 言語を保存していないときは、日本語で出す。
3. 設定画面（`/settings`）で、日本語か英語を選べる。選んだ言語は、そのブラウザーのローカルストレージに保存する。
4. 言語を選ぶと、設定画面を開いたまま、画面の文言がその言語に変わる。
5. どの画面も、開いたときにローカルストレージの言語を読み、その言語で文言を出す。英語を保存しているときは、英語の文言に変わるまで本文を見せない。
6. ローカルストレージを読めないときや、保存した値が日本語か英語のどちらでもないときは、日本語で出す。保存できないときは、選んだ言語をその画面を開いている間だけ使う。
7. `<html>` の `lang` は、出している文言の言語（`ja` か `en`）にする。
8. トップページに、設定画面へのリンクを置く。設定画面には、トップページへ戻るリンクを置く。ほかの画面には、言語を切り替えるリンクを置かない。
9. 言語の選択肢の名前は、選んでいる言語によらず、それぞれの言語で書く（「日本語」「English」）。

文言のファイルは、言語ごとに `src/i18n/messages/ja.json` と `src/i18n/messages/en.json` に置く。2つのファイルは同じキーを持つ。

ローカルストレージのキーは `merb.locale`、値は `ja` か `en` にする。

## 受け入れ条件

この条件をすべて満たせば実装済みとする。テストはこの条件と対応させる。

- [ ] 言語を保存していないとき、トップページが日本語の文言で出て、`<html>` の `lang` が `ja` になる
- [ ] 設定画面で英語を選ぶと、設定画面の文言が英語になり、`<html>` の `lang` が `en` になる
- [ ] 英語を選んだあと、開き直したトップページが英語の文言で出る
- [ ] 英語を選んだあと日本語を選ぶと、日本語の文言に戻る
- [ ] ローカルストレージの値が `ja` と `en` のどちらでもないとき、日本語で出す
- [ ] 日本語と英語の文言のファイルが同じキーを持つことを、単体テストで確かめる
- [ ] ページはビルドのときに静的に作る

## 範囲外

この仕様で扱わないこと。

- 出題の画面と、分類を選ぶ画面
- 問題の JSON の中身の翻訳。問題の読み方は英語のまま
- ブラウザーの言語の設定から言語を選ぶこと
- 端末やブラウザーをまたいで言語の設定をそろえること
