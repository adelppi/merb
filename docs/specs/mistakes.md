# 間違えた問題の記録と再挑戦

- 状態: 合意
- Issue: #59
- 関係する決定: [D-0019](../decisions/D-0019-i18n-and-locale-storage.md)、[D-0026](../decisions/D-0026-mistakes-record.md)

## 目的

`vision.md` の「やること」にある、間違えた問題をあとで再挑戦できるようにする機能に当たる。利用者は、間違えた問題だけを選んで、もう一度解ける。

## 記録

1. 答え合わせで不正解になった問題の id を、端末に記録する。同じ問題を何度間違えても、記録は1つにする。
2. 間違えたあとに正解しても、その場では記録から消さない。
3. 記録するのは問題の id だけにする。回数、日時、正解した問題は記録しない。
4. 保存先は AsyncStorage、キーは `merb.mistakes`、値は問題の id の JSON の配列にする。読めないとき、配列でないとき、文字列でない値は、除くか空の記録として扱う。保存できないときは、アプリを閉じるまで記録を持つ。
5. アプリに同梱した問題にない id は、再挑戦で出さない。

## 再挑戦

1. ホームの「問題を解く」の下に、「間違えた問題」のボタンを置く。控えめなボタン（iOS 26 以上では Liquid Glass、それより前は半透明）で出す。
2. 記録が空のとき（同梱した問題にない id を除いて0問のとき）は、ボタンを押せない。押せない間は、背景を薄い灰色、文字を薄い色で出し、読み上げでは押せない状態として伝える。
3. 押すと、クエリ `mistakes=1` を付けて `/quiz` を開く。出題の画面は、開いた時点の記録にある問題だけから出題する。この問題の集まりは、出題のあいだ変えない。
4. 再挑戦では、分類を選ぶ画面は通らない。出題の画面の戻るボタンは、ホームへ戻る。
5. 再挑戦で、一度も間違えずに正解した問題は、記録から消す。間違えてから正解した問題は、記録に残す。
6. 次の問題の選び方は、[出題の画面](quiz.md#出す問題)のとおり、出す問題の中からランダムに選び、2問以上あるときは直前と同じ問題を選ばない。
7. 再挑戦でない出題でも、不正解になった問題は記録する。

## 文言

画面の文言は、`ja.json` と `en.json` の `Home.mistakes` に足す（日本語は「間違えた問題」、英語は「Missed questions」）。

## 受け入れ条件

この条件をすべて満たせば実装済みとする。テストはこの条件と対応させる。

- [x] 不正解になった問題の id を記録に足す。重ねて足しても1つのままになる（Vitest）
- [x] 記録から id を消せる。ない id を消しても変わらない（Vitest）
- [x] 保存した値を読むとき、配列でない値や文字列でない要素を除く。読めなければ空にする（Vitest）
- [x] 保存と読み出しが `merb.mistakes` で往復する。保存の失敗で例外を出さない（Vitest）
- [x] 記録の id から再挑戦の問題を選ぶ。同梱した問題にない id は除く（Vitest）
- [ ] 記録が空のとき、ホームの「間違えた問題」を押せない（画面）
- [ ] 間違えて答え合わせをした問題が、ホームの「間違えた問題」から出る（画面）
- [ ] 再挑戦で、間違えずに正解した問題が記録から消える。間違えてから正解した問題は残る（Vitest と画面）
- [ ] 再挑戦の出題の戻るボタンで、ホームへ戻る（画面）
- [ ] アプリを閉じて開き直しても、記録が残る（画面）

## 範囲外

この仕様で扱わないこと。

- 間違えた回数、日時、正解率などの進捗の管理
- アカウントと、端末をまたいだ同期
- 記録の手動での削除
- 分類ごとの再挑戦
