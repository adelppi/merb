# 1問を解く出題の画面

- 状態: 実装済み
- Issue: #17、#19、#22、#23、#24
- 関係する決定: [D-0003](../decisions/D-0003-tech-stack.md)、[D-0004](../decisions/D-0004-question-format.md)、[D-0005](../decisions/D-0005-architecture.md)、[D-0006](../decisions/D-0006-locale-storage.md)、[D-0007](../decisions/D-0007-quiz-screen.md)、[D-0008](../decisions/D-0008-category-select.md)、[D-0009](../decisions/D-0009-card-font.md)、[D-0010](../decisions/D-0010-retry-without-button.md)、[D-0011](../decisions/D-0011-question-prompt.md)

## 目的

`vision.md` の「やること」にある、数式の英語での読み方を問う並び替えの問題を出す。利用者は、数式を見て札を並べ、答え合わせをする。間違えたときは、ボタンを押さずにそのまま札を並べ直して解き直すか、答えを見るかを選べる。

## 出す問題

1. 問題は、ビルドのときに `content/questions/` のすべての JSON を読み、[問題の JSON の形](question-format.md)の Zod の形にかけて使う。形に合わない JSON があれば、ビルドを止める。
2. 環境変数 `MERB_QUESTIONS_DIR` があれば、`content/questions/` の代わりにそのフォルダを読む。Playwright のテストは、これで `e2e/fixtures/questions/` のテスト用の問題を読んだビルドを使う。
3. 出す問題は、URL のクエリ `category` で選んだ分類の問題にする。決まりは[出題の範囲を分類から選ぶ画面](category-select.md#出題の画面で出す問題)に書いた。
4. 次の問題は、出す問題の中からランダムに選ぶ。出す問題が2問以上あるときは、直前と同じ問題を選ばない。
5. 出す問題が1問もないときは、出題の画面に「問題がありません」と出し、トップページへ戻るリンクと、分類を選び直すリンクだけを置く。

## 画面

1. 出題の画面の URL は `/quiz` にする。トップページの「問題を解く」から[分類を選ぶ画面](category-select.md)を開き、そこから出題の画面を開く。
2. 出題の画面には、上から順に、問題文、数式、回答エリア、札置き場、ボタンを置く。分類を選び直すリンク（「分類を選び直す」）と、トップページへ戻るリンクも置く。
3. 問題文は、問題の JSON の `prompt` のうち、選んでいる言語のほうを出す（[問題の JSON の形](question-format.md)の「問題文」の節）。日本語を選んでいれば `ja` を、英語を選んでいれば `en` を出す。
4. 数式は KaTeX で描く。設定は、問題の JSON の検査と同じにする（[問題の JSON の形](question-format.md)の「検査」の節）。
5. 札置き場には、[出す札](question-format.md#出す札)の決まりで出した札を、混ぜて並べる。問題を出すたびに混ぜ直す。
6. 問題は、画面を開いたときにブラウザーで選び、札もブラウザーで混ぜる。
7. 札の文字は、数式と同じ KaTeX の書体で出す。回答エリア、札置き場、ドラッグ中の札で同じ書体にする。
   - 札の文字列が英字1文字（`A`〜`Z`、`a`〜`z`）のときは、数式の中の文字と同じ斜体で出す。英単語の `a`（`a half` の `a` など）も、英字1文字なので斜体で出す。
   - ほかの札は、KaTeX の立体で出す。
   - 書体を変えても、判定と札のボタンの名前は、札の文字列のままにする。
8. 答えを見せるときの読み方（「ほかの読み方」と「答え」）は、札の書体にせず、画面の文言と同じ書体で出す。

## 札を運ぶ

答え合わせをする前と、間違えたあとは、次の操作で札を運べる。

1. 札置き場の札をタップすると、その札を回答エリアの末尾へ運ぶ。
2. 回答エリアの札をタップすると、その札を札置き場の元の位置へ戻す。札置き場の札の並びは、問題を出したときから変わらない。
3. 札置き場の札をドラッグして回答エリアに落とすと、その位置へ入れる。回答エリアの札の上に落とすとその札の前に、札のないところに落とすと末尾に入れる。
4. 回答エリアの札をドラッグすると、回答エリアの中で並べ替えられる。札の上に落とすとその札の位置へ、札のないところに落とすと末尾へ移す。
5. 回答エリアの札をドラッグして札置き場に落とすと、札置き場の元の位置へ戻す。
6. 札置き場の中では並べ替えない。札置き場の札を札置き場に落としても、何も変わらない。
7. ドラッグは、マウスでは少し動かしたとき、タッチでは少し長く押したときに始める。それより短い操作はタップとして扱う。

## 答え合わせ

1. 答え合わせは、「答え合わせ」のボタンを押したときにする。回答エリアに札が1枚もなくても押せる。
2. 判定は、[問題の JSON の形](question-format.md)の「判定」の節のとおりにする。札が1枚もなければ不正解にする。
3. 正解したあとと、答えを見たあとは、次の問題を出すまで札を運べない。

### 正解したとき

1. 「正解」と出す。
2. 読み方が複数ある問題では、回答エリアに並べたもの以外の読み方を、「ほかの読み方」として `answers` の順に見せる。
3. 「次の問題」のボタンを出す。押すと次の問題を出す。

### 間違えたとき

1. 「不正解」と出す。回答エリアの札は、並べたまま見せる。
2. 「答え合わせ」と「答えを見る」のボタンを出す。「次の問題」のボタンは出さない。
3. ボタンを押さずに、そのまま札を運べる（「札を運ぶ」の節）。札を運んで回答エリアの並びが変わったら、「不正解」の表示を消す。「答えを見る」のボタンは、次の問題を出すまで出したままにする。
4. 札を並べ直してから、または並べ直さずに、もう一度「答え合わせ」を押せる。判定は「答え合わせ」の節の1と2のとおりにし、正解なら「正解したとき」のとおりにする。
5. 続けて不正解になったときも、答え合わせのたびに「不正解」を出し直す。出し直すときは、「不正解」を 0.3 秒ほど左右に小さく揺らす。利用者が動きを減らす設定（`prefers-reduced-motion: reduce`）にしているときは、揺らさずに、0.3 秒ほどかけて薄い色から元の色に戻して出す。
6. 間違えた回数は数えず、見せない。
7. 「答えを見る」を押すと、「答え」として、すべての読み方を `answers` の順に見せ、「次の問題」のボタンを出す。

### 読み方の見せ方

読み方は、正解の `text` があれば `text` を、なければ `cards` を半角スペース1つでつないだものを見せる。

## 文言

画面の文言は、`src/i18n/messages/ja.json` と `en.json` から出す（[画面の文言の言語の切り替え](i18n.md)）。数式と札と読み方は、言語によらず問題の JSON のまま出す。問題文は、「画面」の節のとおり、選んでいる言語のものを問題の JSON から出す。

## 受け入れ条件

この条件をすべて満たせば実装済みとする。テストはこの条件と対応させる。

- [x] `/quiz` を開くと、数式と、混ぜた札が出る
- [x] 札置き場の札をタップすると回答エリアの末尾へ、回答エリアの札をタップすると札置き場の元の位置へ動く（Vitest と Playwright）
- [x] 札置き場の札を、ドラッグで回答エリアへ運べる（Playwright）
- [x] 回答エリアの中での並べ替えと、札置き場へ戻す動きが「札を運ぶ」の節のとおりになる（Vitest）
- [x] 札を並べて答え合わせをすると、正解なら「正解」と、ほかの読み方と、「次の問題」が出る（Vitest と Playwright）
- [x] 間違えて答え合わせをすると、「不正解」と、「答え合わせ」と「答えを見る」のボタンが出て、「次の問題」のボタンは出ない（Playwright）
- [x] 間違えたあと、ボタンを押さずに札を運び、もう一度答え合わせができる（Vitest と Playwright）
- [x] 間違えたあとに札を運んで並びが変わると、「不正解」の表示が消え、「答えを見る」のボタンは残る（Vitest と Playwright）
- [x] 続けて不正解になると、答え合わせのたびに「不正解」を出し直す（Vitest と Playwright）
- [x] 「答えを見る」で、すべての読み方が出る（Vitest と Playwright）
- [x] 札が1枚もなくても答え合わせができ、不正解になる（Vitest）
- [x] 正解したあとと、答えを見たあとは、次の問題を出すまで札を運べない（Vitest）
- [x] 札を混ぜる処理は、渡した乱数で結果が決まり、札をなくしたり増やしたりしない（Vitest）
- [x] 次の問題を選ぶ処理は、問題が2問以上あれば直前と同じ問題を選ばない（Vitest）
- [x] 問題のフォルダの JSON を読んで、すべての問題を返す。テスト用の問題も、問題の JSON の検査を通る（Vitest）
- [x] 問題が1問もないときは「問題がありません」と出す（Vitest）
- [x] 英語を選んでいるときは、出題の画面の文言が英語で出る（Playwright）
- [x] 数式の上に、選んでいる言語の問題文が出る。日本語を選んでいれば日本語の、英語を選んでいれば英語の問題文になる（Playwright）
- [x] ページはビルドのときに静的に作る
- [x] 英字1文字の札は KaTeX の斜体で、ほかの札は KaTeX の立体で出る。札のボタンの名前は札の文字列のままになる（Vitest と Playwright）

## 範囲外

この仕様で扱わないこと。

- 分類を選ぶ画面（[出題の範囲を分類から選ぶ画面](category-select.md)）
- 問題の JSON の中身を作ること
- キーボードでのドラッグ。キーボードでは、札のボタンを押してタップと同じに運ぶ
- 解いた問題の数や正解の数を数えること（`vision.md` の「やらないこと」の「進捗の管理」と「ゲーム性」）
