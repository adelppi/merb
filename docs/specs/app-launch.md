# アイコンと起動画面

- 状態: 合意
- Issue: #74
- 関係する決定: [D-0033](../decisions/D-0033-icon-and-splash.md)

## 目的

利用者がホーム画面と起動の瞬間に、merb のアイコンと起動画面を見られるようにする。App Store へ提出するビルドに必要なものを用意する。

## 振る舞い

1. ホーム画面のアイコンは `assets/merb.icon` を使う。Icon Composer で作ったファイルで、`app.json` の `ios.icon` に指定する。
2. アプリを開くと、画面の中央に幅 120 のシグマを出す。
3. 背景は `#f2f2f7`、シグマは藍（`#3658ac`）にする。
4. アプリは端末の設定によらず、常に明るい表示で出す。ダークモードの端末でも、起動画面、ステータスバー、画面を明るい表示にする。
5. アプリの準備ができたら起動画面を閉じる。閉じる時期を遅らせる処理は入れない。

## 受け入れ条件

- [ ] Release 構成のビルドで、ホーム画面に `merb.icon` のアイコンが出る
- [ ] Release 構成のビルドで、起動画面が 3 のとおりに出る
- [ ] ダークモードの端末でも、Release 構成のビルドの起動画面とステータスバーが明るい表示で出る

## 範囲外

- Expo Go での表示。Expo Go は、アプリのアイコンと起動画面を使わない
- アプリの画面のダークモード対応
- Expo の依存の版をそろえること
