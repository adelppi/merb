# 出題の範囲を分類から選ぶ画面（ホーム）

- 状態: 合意
- Issue: #19、#36、#70
- 関係する決定: [D-0003](../decisions/D-0003-tech-stack.md)、[D-0004](../decisions/D-0004-question-format.md)、[D-0008](../decisions/D-0008-category-select.md)、[D-0012](../decisions/D-0012-native-app.md)、[D-0018](../decisions/D-0018-design-open-questions.md)、[D-0019](../decisions/D-0019-i18n-and-locale-storage.md)、[D-0020](../decisions/D-0020-category-navigation.md)、[D-0030](../decisions/D-0030-merge-home-categories.md)
- デザイン: [docs/design/](../design/README.md) の分類を選ぶ（2f）

## 目的

`vision.md` の「やること」にある「出題の範囲は、観点シートの分類から選ぶ。分類は複数選べる。どの分類からも出すランダムの出題もできる。」に当たる。利用者は、分類を1つ以上選んで出題を始める。すべての分類から出すときは、「すべて選択」で全部を選ぶ。

## 画面のつながり

画面の移動は Expo Router の Stack で行う。

1. 分類を選ぶ画面は、ホームを兼ねる。ルートは `/` にする（[D-0030](../decisions/D-0030-merge-home-categories.md)）。
2. 分類を選ぶ画面から、[出題の画面](quiz.md)（`/quiz`）を開く。選んだ分類は、クエリ `categories` に分類の id をコンマで区切って渡す（例: `/quiz?categories=numbers,fractions`）。
3. クエリのない `/quiz` は、すべての分類から出す。この画面からは開かない。
4. 出題の画面の戻るボタンは、分類を選ぶ画面へ戻る。戻ったとき、分類を選ぶ画面は直前に選んでいた分類を選んだ状態で出る。

## 分類を選ぶ画面

1. 大見出し「merb」を Stack のヘッダーで出す。大見出しは iOS 純正の大タイトルで、ヘッダーの背景は透明にして、画面の背景になじませる。ヘッダーの右上に、設定画面を開く歯車のボタンを置く（[画面の文言の言語の切り替え](i18n.md)）。
2. 大見出しの下に、一覧の見出しの行を置く。左に「分類を選ぶ」、右端に「すべて選択」のボタンを出す。
3. 見出しの行の下に、分類の一覧を置く。[問題の JSON の形](question-format.md#分類)の8つの分類を、その表の順に1行ずつ並べる。1行には分類の名前を左に出し、選んでいる行には右端にチェックを出す。行をタップすると、選んだ状態と選んでいない状態が切り替わる。分類は複数選べる。
4. 問題が1問もない分類の行も出すが、選べないようにする。文字を薄い色で出し、タップしても切り替わらない。読み上げでは、押せない状態として伝える。
5. 「すべて選択」を押すと、問題がある分類をすべて選ぶ。問題がある分類をすべて選んでいるときは、ボタンを「すべて解除」に変える。「すべて解除」を押すと、どの分類も選んでいない状態にする。タップできる領域の高さは 44 にする。
6. 画面の下に、「選んだ分類で始める」のボタンと、[間違えた問題](mistakes.md#再挑戦)のボタンを縦に並べて置く。一覧が長いときも、一覧の末尾が下のボタンに隠れず、スクロールで見えるようにする。
7. 「選んだ分類で始める」のボタンは、分類を1つも選んでいないときは押せない。押せない間は、背景を薄い灰色、文字とアイコンを薄い色で出し、読み上げでは押せない状態として伝える。押すと、選んだ分類を一覧の順にコンマでつないで `categories` に付け、出題の画面を開く。
8. 選んだ分類は、選択を変えるたびに端末に保存する。次に開いたときは、保存した分類を選んだ状態で出す。保存がないときは、どの分類も選んでいない状態にする。
9. 背景は `#f2f2f7`、分類の一覧は白の角丸、チェックは藍にする。「選んだ分類で始める」は、iOS 26 以上では藍に色付けした Liquid Glass、それより前は藍の背景で出す（[D-0027](../decisions/D-0027-prominent-glass.md)）。「すべて選択」は背景のない藍の文字で出す。
10. ボタンのアイコンは SF Symbols で出す。「選んだ分類で始める」は `play.fill`、「すべて選択」は `checkmark.circle`、「すべて解除」は `xmark.circle` にする。分類の行には、チェックのほかのアイコンを付けない。

## 選んだ分類の保存

1. 保存先は AsyncStorage、キーは `merb.categories`、値は分類の id の JSON の配列にする。
2. 読むときは、分類の id でないもの、問題が1問もない分類、重なったものを除き、分類の表の順に並べる。読めないとき、配列でないときは、どの分類も選んでいない状態にする。
3. 保存できないときは、アプリを閉じるまで選んだ分類を持つ。
4. 保存を読み終えてから画面を出す。

## 出題の画面で出す問題

出題の画面の振る舞いは [quiz.md](quiz.md) に書く。ここには、分類を選ぶ画面から渡すクエリの読み方を書く。

1. 出題の画面は、開いたときにクエリ `categories` を読み、コンマで区切った分類の id のうち、あるものの問題だけを出す。分類の id でないものと、重なったものは除く。
2. `categories` がないときや、除いたあとに分類が1つも残らないときは、すべての分類の問題から出す。
3. 次の問題は、出す問題の中からランダムに選ぶ。出す問題が2問以上あるときは、直前と同じ問題を選ばない。
4. 出す問題が1問もないときは、[出題の画面](quiz.md)の決まりのとおり「問題がありません」と出す。

## 文言

画面の文言と分類の名前は、`src/i18n/messages/ja.json` と `en.json` から `useI18n()` で読んで出す（[画面の文言の言語の切り替え](i18n.md)）。分類の名前は次のとおり。日本語は観点シートの節の名前と同じにする。英語は、観点シートの節に英語の名前が書いてあればそれを使う。

| 分類の id | 日本語 | 英語 |
|---|---|---|
| `numbers` | 数 | Numbers |
| `fractions` | 分数 | Fractions |
| `scripts-powers-roots` | 添え字・累乗・根号 | Subscripts, powers, roots |
| `arithmetic` | 四則演算・括弧 | Arithmetic, parentheses |
| `vectors-functions` | ベクトル・行列・関数 | Vectors, matrices, functions |
| `calculus` | 微分・積分・総和 | Derivatives, integrals, sums |
| `relations` | 等式・不等式・関係記号 | Equations, inequalities, relations |
| `combined` | まとまった数式 | Combined formulas |

## 受け入れ条件

この条件をすべて満たせば実装済みとする。テストはこの条件と対応させる。画面の表示と操作は単体テストの対象ではないので、「画面」と書いた条件はシミュレーターで確かめる。操作テストの道具は Maestro で、手元から実行する（[D-0021](../decisions/D-0021-operation-test-tool.md)）。

- [ ] `/` に大見出し「merb」、右上の歯車、8つの分類が表の順に出る（画面）
- [ ] 分類は複数選べる。行をタップするたびに、選んだ状態と選んでいない状態が切り替わる（Vitest と画面）
- [ ] 分類を1つも選んでいないときは、「選んだ分類で始める」を押せない（Vitest と画面）
- [ ] 問題が1問もない分類は、選べない（Vitest と画面）
- [ ] 「すべて選択」で問題がある分類がすべて選ばれ、ボタンが「すべて解除」に変わる（Vitest と画面）
- [ ] 「すべて解除」で、どの分類も選んでいない状態になる（Vitest と画面）
- [ ] 分類を選んで始めると、選んだ分類を表の順にコンマでつないだ `categories` を付けて `/quiz` を開く（Vitest と画面）
- [ ] `categories` の分類の id でないものと重なったものを除き、残らなければすべての分類から出す（Vitest）
- [ ] 出題の画面の戻るボタンで分類を選ぶ画面へ戻ると、選んでいた分類を選んだ状態で出る（Maestro: `back`）
- [ ] アプリを開き直すと、最後に選んだ分類を選んだ状態で出る（Vitest と Maestro: `saved-categories`）
- [ ] 保存の値が壊れていても、分類の id でないものと問題のない分類を除いて読める（Vitest）
- [ ] 英語を選んでいるときは、画面の文言と分類の名前が英語で出る（画面）
- [ ] 文言のファイルに、8つの分類すべての名前がある（Vitest）

## 範囲外

この仕様で扱わないこと。

- 問題の JSON の中身を作ること
- 解いた問題の数や正解の数を数えること（`vision.md` の「やらないこと」の「進捗の管理」と「ゲーム性」）
- 分類ごとの問題の数を出すこと
- 出題の画面（[quiz.md](quiz.md)）、設定画面
