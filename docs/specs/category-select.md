# 出題の範囲を分類から選ぶ画面

- 状態: 合意
- Issue: #19、#36
- 関係する決定: [D-0003](../decisions/D-0003-tech-stack.md)、[D-0004](../decisions/D-0004-question-format.md)、[D-0008](../decisions/D-0008-category-select.md)、[D-0012](../decisions/D-0012-native-app.md)、[D-0018](../decisions/D-0018-design-open-questions.md)、[D-0019](../decisions/D-0019-i18n-and-locale-storage.md)、[D-0020](../decisions/D-0020-category-navigation.md)
- デザイン: [docs/design/](../design/README.md) の分類を選ぶ（2f）

## 目的

`vision.md` の「やること」にある「出題の範囲は、観点シートの分類から選ぶ。分類は複数選べる。どの分類からも出すランダムの出題もできる。」に当たる。利用者は、分類を1つ以上選んで出題を始めるか、すべての分類から出す出題を始める。

## 画面のつながり

画面の移動は Expo Router の Stack で行う。

1. 分類を選ぶ画面のルートは `/categories` にする。ホームの「問題を解く」は、この画面を開く。
2. 分類を選ぶ画面の戻るボタンは、ホームへ戻る。
3. 分類を選ぶ画面から、[出題の画面](quiz.md)（`/quiz`）を開く。選んだ分類は、クエリ `categories` に分類の id をコンマで区切って渡す（例: `/quiz?categories=numbers,fractions`）。
4. 「すべての分類から出す」は、クエリを付けずに `/quiz` を開く。クエリのない `/quiz` は、すべての分類から出す。
5. 出題の画面の戻るボタンは、分類を選ぶ画面へ戻る。戻ったとき、分類を選ぶ画面は直前に選んでいた分類を選んだ状態で出る。分類を選ぶ画面は、出題の画面を開いても閉じずに Stack に残るので、選んだ状態はその画面が持ち続ける。

## 分類を選ぶ画面

1. 画面の左上に戻るボタンを、その下に大見出し「分類を選ぶ」を置く。戻るボタンと大見出しは、設定画面と同じく Stack のヘッダーで出す。
2. 大見出しの下に、分類の一覧を置く。[問題の JSON の形](question-format.md#分類)の8つの分類を、その表の順に1行ずつ並べる。1行には分類の名前を左に出し、選んでいる行には右端にチェックを出す。行をタップすると、選んだ状態と選んでいない状態が切り替わる。分類は複数選べる。
3. 問題が1問もない分類の行も出すが、選べないようにする。文字を薄い色で出し、タップしても切り替わらない。読み上げでは、押せない状態として伝える。
4. 画面の下に、「選んだ分類で始める」のボタンと「すべての分類から出す」のボタンを縦に並べて置く。一覧が長いときも、一覧の末尾が下のボタンに隠れず、スクロールで見えるようにする。
5. 「選んだ分類で始める」のボタンは、分類を1つも選んでいないときは押せない。押せない間は、背景を薄い灰色、文字を薄い色で出し、読み上げでは押せない状態として伝える。押すと、選んだ分類を一覧の順にコンマでつないで `categories` に付け、出題の画面を開く。
6. 「すべての分類から出す」のボタンは、分類を選んでいるかどうかによらず押せる。押すと、クエリを付けずに出題の画面を開く。選んだ状態は変えない。
7. 画面を最初に開いたとき、どの分類も選んでいない状態にする。選んだ状態は、この画面が閉じるまで持ち、端末に保存しない。ホームへ戻って閉じると消える。
8. 背景は `#f2f2f7`、分類の一覧は白の角丸、チェックと「選んだ分類で始める」の背景は藍にする。iOS 26 以上では、戻るボタンと「すべての分類から出す」を Liquid Glass で出す。それより前は、半透明の背景で出す（[D-0018](../decisions/D-0018-design-open-questions.md)）。アイコンは SF Symbols で出す。

## 出題の画面で出す問題

出題の画面の振る舞いは [quiz.md](quiz.md) に書く。ここには、分類を選ぶ画面から渡すクエリの読み方を書く。

1. 出題の画面は、開いたときにクエリ `categories` を読み、コンマで区切った分類の id のうち、あるものの問題だけを出す。分類の id でないものと、重なったものは除く。
2. `categories` がないときや、除いたあとに分類が1つも残らないときは、すべての分類の問題から出す。
3. 次の問題は、出す問題の中からランダムに選ぶ。出す問題が2問以上あるときは、直前と同じ問題を選ばない。
4. 出す問題が1問もないときは、[出題の画面](quiz.md)の決まりのとおり「問題がありません」と出す。

## 文言

画面の文言と分類の名前は、`src/i18n/messages/ja.json` と `en.json` から `useI18n()` で読んで出す（[画面の文言の言語の切り替え](i18n.md)）。分類の名前は次のとおり。日本語は観点シートの節の名前と同じにする。英語は、観点シートの節に英語の名前が書いてあればそれを使う。

| 分類の id | 日本語 | 英語 |
|---|---|---|
| `numbers` | 数 | Numbers |
| `fractions` | 分数 | Fractions |
| `scripts-powers-roots` | 添え字・累乗・根号 | Suffixes, powers, roots |
| `arithmetic` | 四則演算・括弧 | Arithmetic, parentheses |
| `vectors-functions` | ベクトル・行列・関数 | Vectors, matrices, functions |
| `calculus` | 微分・積分・総和 | Derivatives, integrals, sums |
| `relations` | 等式・不等式・関係記号 | Equations, inequalities, relations |
| `combined` | まとまった数式 | Combined formulas |

## 受け入れ条件

この条件をすべて満たせば実装済みとする。テストはこの条件と対応させる。画面の表示と操作は単体テストの対象ではないので（[OQ-015](../open-questions.md#oq-015)）、「画面」と書いた条件はシミュレーターで確かめる。

- [ ] ホームの「問題を解く」から分類を選ぶ画面が開き、8つの分類が表の順に出る（画面）
- [ ] 分類は複数選べる。行をタップするたびに、選んだ状態と選んでいない状態が切り替わる（Vitest と画面）
- [ ] 分類を1つも選んでいないときは、「選んだ分類で始める」を押せない（Vitest と画面）
- [ ] 問題が1問もない分類は、選べない（Vitest と画面）
- [ ] 分類を選んで始めると、選んだ分類を表の順にコンマでつないだ `categories` を付けて `/quiz` を開く（Vitest と画面）
- [ ] 「すべての分類から出す」で始めると、クエリなしで `/quiz` を開く（Vitest と画面）
- [ ] `categories` の分類の id でないものと重なったものを除き、残らなければすべての分類から出す（Vitest）
- [ ] 出題の画面の戻るボタンで分類を選ぶ画面へ戻ると、選んでいた分類を選んだ状態で出る（画面）
- [ ] 分類を選ぶ画面の戻るボタンで、ホームへ戻る（画面）
- [ ] 英語を選んでいるときは、画面の文言と分類の名前が英語で出る（画面）
- [ ] 文言のファイルに、8つの分類すべての名前がある（Vitest）

## 範囲外

この仕様で扱わないこと。

- 問題の JSON の中身を作ること
- 解いた問題の数や正解の数を数えること（`vision.md` の「やらないこと」の「進捗の管理」と「ゲーム性」）
- 分類ごとの問題の数を出すこと
- 選んだ分類を、次に開いたときのために保存すること（[D-0008](../decisions/D-0008-category-select.md)）
- 出題の画面（[quiz.md](quiz.md)）、ホーム、設定画面
