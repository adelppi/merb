# 出題の範囲を分類から選ぶ画面

- 状態: 実装済み
- Issue: #19
- 関係する決定: [D-0003](../decisions/D-0003-tech-stack.md)、[D-0004](../decisions/D-0004-question-format.md)、[D-0006](../decisions/D-0006-locale-storage.md)、[D-0007](../decisions/D-0007-quiz-screen.md)、[D-0008](../decisions/D-0008-category-select.md)

## 目的

`vision.md` の「やること」にある「出題の範囲は、観点シートの分類から選ぶ。分類は複数選べる。どの分類からも出すランダムの出題もできる。」に当たる。利用者は、分類を1つ以上選んで出題を始めるか、すべての分類から出す出題を始める。

## 画面のつながり

1. 分類を選ぶ画面の URL は `/categories` にする。
2. トップページの「問題を解く」のリンクは、分類を選ぶ画面を開く。
3. 分類を選ぶ画面から、[出題の画面](quiz.md)（`/quiz`）を開く。選んだ分類は、URL のクエリ `category` で渡す。分類を1つ選ぶごとに `category=<分類の id>` を1つ付ける（例: `/quiz?category=numbers&category=fractions`）。
4. `category` を付けずに `/quiz` を開くと、すべての分類から出す。
5. 出題の画面に、分類を選ぶ画面へのリンク（「分類を選び直す」）を置く。リンクには、出題の画面の URL と同じ `category` を付ける。

## 分類を選ぶ画面

1. 画面には、上から順に、見出し、分類の選択肢、「選んだ分類で始める」のボタン、「すべての分類から出す」のリンク、トップページへ戻るリンクを置く。
2. 分類の選択肢は、[問題の JSON の形](question-format.md#分類)の8つの分類を、その表の順にチェックボックスで並べる。複数選べる。
3. 問題が1問もない分類も選択肢に出すが、選べないようにする。
4. 画面を開いたとき、URL のクエリ `category` にある分類を選んだ状態にする。分類の id でないもの、重なったもの、問題が1問もない分類は除く。`category` がなければ、どの分類も選んでいない状態にする。
5. 「選んだ分類で始める」のボタンは、分類を1つも選んでいないときは押せない。押すと、選んだ分類を選択肢の順に `category` に付けて出題の画面を開く。
6. 「すべての分類から出す」のリンクは、`category` を付けずに出題の画面を開く。
7. 選んだ分類は保存しない。`category` を付けずに分類を選ぶ画面を開くと、どの分類も選んでいない状態から始める。

## 出題の画面で出す問題

1. 出題の画面は、開いたときに URL のクエリ `category` を読み、そこにある分類の問題だけを出す。分類の id でないものと、重なったものは除く。
2. `category` がないときや、除いたあとに分類が1つも残らないときは、すべての分類の問題から出す。
3. 次の問題は、出す問題の中からランダムに選ぶ。出す問題が2問以上あるときは、直前と同じ問題を選ばない。
4. 出す問題が1問もないときは、[出題の画面](quiz.md)の決まりのとおり「問題がありません」と出す。

## 文言

画面の文言と分類の名前は、`src/i18n/messages/ja.json` と `en.json` から出す（[画面の文言の言語の切り替え](i18n.md)）。分類の名前は次のとおり。日本語は観点シートの節の名前と同じにする。英語は、観点シートの節に英語の名前が書いてあればそれを使う。

| 分類の id | 日本語 | 英語 |
|---|---|---|
| `numbers` | 数 | Numbers |
| `fractions` | 分数 | Fractions |
| `scripts-powers-roots` | 添え字・累乗・根号 | Suffixes, powers, roots |
| `arithmetic` | 四則演算・括弧 | Arithmetic, parentheses |
| `vectors-functions` | ベクトル・行列・関数 | Vectors, matrices, functions |
| `calculus` | 微分・積分・総和 | Derivatives, integrals, sums |
| `relations` | 等式・不等式・関係記号 | Equations, inequalities, relations |
| `combined` | まとまった数式 | Combined formulas |

## 受け入れ条件

この条件をすべて満たせば実装済みとする。テストはこの条件と対応させる。

- [x] トップページの「問題を解く」から分類を選ぶ画面が開き、8つの分類が選択肢の順に出る（Playwright）
- [x] 分類を1つも選んでいないときは、「選んだ分類で始める」を押せない（Playwright）
- [x] 問題が1問もない分類は、選べない（Vitest と Playwright）
- [x] 分類を選んで始めると、`category` を付けた出題の画面が開き、選んだ分類の問題だけが「次の問題」で続けて出る（Vitest と Playwright）
- [x] 「すべての分類から出す」で始めると、すべての分類の問題から出る（Vitest と Playwright）
- [x] `category` の分類の id でないものと重なったものを除き、残らなければすべての分類から出す（Vitest）
- [x] 出題の画面の「分類を選び直す」から、同じ分類を選んだ状態の分類を選ぶ画面が開く（Playwright）
- [x] 英語を選んでいるときは、分類を選ぶ画面の文言と分類の名前が英語で出る（Vitest と Playwright）
- [x] 文言のファイルに、8つの分類すべての名前がある（Vitest）
- [x] ページはビルドのときに静的に作る

## 範囲外

この仕様で扱わないこと。

- 問題の JSON の中身を作ること
- 解いた問題の数や正解の数を数えること（`vision.md` の「やらないこと」の「進捗の管理」と「ゲーム性」）
- 分類ごとの問題の数を出すこと
- 選んだ分類を、次に開いたときのために保存すること（[D-0008](../decisions/D-0008-category-select.md)）
