# D-0012 ネイティブアプリにし、Web 版をやめる

- 日付: 2026-11-03
- 決めた人: adelppi
- 関係する Issue と PR: #29
- 解決した未解決の項目: OQ-014
- 置き換える記録: D-0003 のうち、フレームワーク（Next.js の App Router）と実行環境（Vercel）の点。D-0005 のうち、Next.js の Server Component と Client Component の境目、`src/app/` にページを置く点

## 背景

merb をネイティブアプリにする。スタックは React Native と Expo。いまは Next.js の Web 版があり（[D-0003](D-0003-tech-stack.md)）、Web 版との関係、リポジトリの構成、共有するコード、問題の JSON の渡し方、言語の決め方を決める必要があった。

## 決定

- アプリは React Native と Expo で作る。
- Web 版（Next.js）はやめ、リポジトリから削除する。Expo のアプリ 1つにする。ワークスペースで Web 版とコードを共有する構成は採らない。
- 既存の `src/questions/`、`src/quiz/`、`content/` は、Expo のアプリの中で使い続ける。画面の部品と、Next.js の画面は作り直す。
- 問題の JSON は、アプリのビルドに同梱する。ビルドのときに Zod で検査する。サーバーから配信しない。
- 言語は [D-0006](D-0006-locale-storage.md) と同じく、設定画面で日本語か英語を選び、端末に保存する。保存がなければ日本語で出す。端末の言語の設定には合わせない。
- 判断の基準は変えない。出す問題の読み方が正しいこと、画面がシンプルであること、スマートフォンでも操作しやすいこと（`vision.md`）。

## ほかの選択肢

- Web 版を残し、ネイティブ版を追加する案。採らなかった。Web 版をやめ、ネイティブ版だけにする案を選んだ。
- Expo で Web も出し、Next.js をやめる案。採らなかった。ネイティブ版だけにする案を選んだ。
- pnpm のワークスペースで Web 版、ネイティブ版、共有するコードに分ける案。Web 版をやめるので、共有する相手がなくなり、採らなかった。
- 別のリポジトリにする案と、同じリポジトリで共有せずにコードを写す案。Web 版をやめるので、検討の対象から外した。
- 問題の JSON をサーバーから配信する案。[D-0003](D-0003-tech-stack.md) の「サーバーで処理することがない」と食い違うので採らなかった。
- 言語を端末の言語の設定に合わせる案。D-0006 と同じ決め方のほうを選んだ。

## 根拠

- 問題の JSON を同梱し、Zod の検査を継続すれば、`vision.md` の判断の基準の1つ目「出す問題の読み方が正しいこと」を、Web 版のときと同じ方法で守れる。
- 言語の決め方を D-0006 と同じにすると、`vision.md` の「やらないこと」にある学習の記録の保存には当たらないまま、設定を端末に残せる。
- `vision.md` の「やらないこと」（アカウント、学習の記録の保存と同期、進捗の管理、ゲーム性、サーバーでの LLM 呼び出し）には当たらない。
