# D-0023 札の位置を UI スレッドで決める作りに組み直し、動かし始めの判定を長押しから移動量に変える

- 日付: 2026-11-03
- 決めた人: adelppi が不具合と欲しい動き、参考にするリポジトリを伝え、AI が組み方を選んだ。PR で adelppi が確かめる
- 関係する Issue と PR: #54
- 解決した未解決の項目: なし
- 置き換える記録: [D-0016](D-0016-math-and-drag-libs.md) のうち、ドラッグを 250 ミリ秒の長押しのあとに始める点。[D-0022](D-0022-drag-with-gesture-handler-v3.md) のうち、動かない原因の見立てと、出題の画面のスクロールを Gesture Handler の `ScrollView` にする点

## 背景

[D-0022](D-0022-drag-with-gesture-handler-v3.md) のあとも、札を長押ししてドラッグできなかった。adelppi からは、札を持ち上げたときに落ちる位置が見えないこと、落ちる位置の札が避けないことも伝えられた。出題の画面をスクロールさせないことも頼まれた。

最初に組み直した版（#55 の最初のコミット）では、ドラッグはできるようになったが、操作性がよくないと adelppi から指摘があった。その版は、指を動かすたびに JS スレッドへ値を渡し、React の再描画で空きの枠と札の並びを変えていた。そのうえで、次の2つのリポジトリを読んだ。

- [jamsch/react-native-duo-drag-drop](https://github.com/jamsch/react-native-duo-drag-drop)（MIT）。Duolingo 風の単語バンクのライブラリ。Gesture Handler と Reanimated で組んでいる。
- [RafaelGoulartB/duolingo-drag-and-drop](https://github.com/RafaelGoulartB/duolingo-drag-and-drop)（MIT）。William Candillon の動画をなぞった 2021 年のデモアプリ（Expo 39、Reanimated 2 のアルファ版）。上のライブラリはこの系統にある。

## 決定

- 札の位置、並べ替え、ほかの札が避ける動きは、すべて UI スレッドの共有値で決める。React の再描画は、札を運び終えたときに reducer へ知らせるときだけ起きる。しくみは、上の2つのリポジトリに共通する作りに基づく。
  - 札ごとに、回答エリアの何番目か（札置き場なら -1）を持つ。回答エリアの札の位置は、この並びと札の幅から、行の折り返しを数えて求める。
  - 札はすべて盤面の上に絶対位置で置き、位置を `withTiming` で動かす。並びが変わると、ほかの札は新しい位置へアニメーションで動く。
  - 札置き場には、札ごとの元の位置に灰色の枠を置く。札がどこにあっても、元の位置はこの枠で決まる。
- 入る位置は、指に対する札の並びで決める。上の行の札と、同じ行で中心が指より左にある札の数を、位置の番号にする。指を動かすたびに決め直す。
- ドラッグ中に `zIndex` を切り替えたり、札の View を並べ替えたりしない。切り替えると View の並びが入れ替わり、ジェスチャーが取り消された（シミュレーター、iOS 26.5 で確かめた）。持ち上げた札は、札ごとに用意した見た目（Ghost）を盤面の最後に置き、持ち上げている間だけ見せる。後ろの View ほど手前に描かれる。
- 入る位置の空きの枠（点線）も、札ごとに用意した View を、札の下に置く。
- ドラッグは、指を 6 ポイント動かしたときに始める。長押しの待ち時間はなくす。
- 出題の画面は、スクロールしない。`ScrollView` をやめ、ふつうの `View` にする。
- 回答エリアは、札をすべて並べても収まる高さに固定する。
- 並びの計算は、`src/quiz/board.ts` の純粋な関数にして、Vitest で確かめる。ライブラリは足さない。

## ほかの選択肢

- `react-native-duo-drag-drop` をそのまま入れる案。ソースを読んで、次の理由で採らなかった。入れて試してはいない。
  - peer dependency が Gesture Handler `^2.2.1` で、このアプリは 3.3 を使っている。
  - 札置き場と回答エリアのあいだに「不正解」の帯を出す、正解したあとに札置き場を隠す、札の状態を reducer が持つ、という作りに合わせるには、中身を直す必要がある。
  - 札の色が、回答エリアにあるかどうかで変わる。ライブラリは、札の見た目を並びの変化に合わせて切り替える手段を持たない。
- `react-native-sortables`、`react-native-reanimated-dnd`。確かめた範囲では、札置き場から回答エリアへ移しながら、回答エリアの札が避ける例は見つからなかった。
- 長押しでドラッグを始める作りを続ける案。長押しは、スクロールとの取り合いを避けるために置いたものだった。スクロールをやめたので、待ち時間を置く理由がなくなった。

## 根拠

- `zIndex` の影響は、シミュレーターの Expo Go で、Maestro の `swipe` を使って確かめた。切り替えているときは、動かし始めた直後にジェスチャーが取り消され、外すと最後まで続いた。
- 最初に組み直した版が重かったのは、指の動きごとに JS スレッドを通っていたため。2つのリポジトリは、これを UI スレッドの中で終わらせている。
- ライセンスは、どちらも MIT。コードは写さず、しくみに基づいて書く。`src/components/CardBoard.tsx` の冒頭に、参考にしたことを書く。
