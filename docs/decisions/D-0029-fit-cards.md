# D-0029 札が画面に収まらないときは、札を同じ割合で縮める

- 日付: 2026-11-04
- 決めた人: adelppi が直してほしいことを伝え、AI が方法を選んだ。PR で adelppi が確かめる
- 関係する Issue と PR: #65
- 解決した未解決の項目: なし
- 置き換える記録: なし。D-0023 の、出題の画面をスクロールしない決定と、回答エリアの高さを固定する決定は変えない

## 背景

長い問題で、札が画面に収まらない場合があると、adelppi から指摘があった。回答エリアは札をすべて並べても収まる高さに固定しているので、札の枚数が多いと、回答エリアと札置き場の両方が高くなり、札置き場が下のボタンの裏へはみ出す。問題の中には、札が 26 枚から 28 枚のものがある。

## 決定

- 回答エリア、「不正解」の表示、札置き場が下のボタンより上に収まらないときは、札の高さ、幅、角丸、文字の大きさ、札の間隔を同じ割合で縮める。
- 割合は 1 から 0.05 ずつ下げ、収まる最初の値を使う。下限は 0.6 にする。下限でも収まらないときは、0.6 で出す。
- 使える高さは、問題文と数式の下から、下のボタンの上までにする。数式の高さが決まって、使える高さが変わったら、割合を計算し直す。
- 札の幅は、見えない札で縮める前の幅を測り、割合を掛けて求める。札置き場の札の位置も計算で決める。
- 計算は `src/quiz/board.ts` の `fitBoard` にして、Vitest で確かめる。

## ほかの選択肢

- 出題の画面をスクロールさせる案。D-0023 で、スクロールさせないと決めている。
- 札の文字だけを小さくする案。札の高さと間隔が変わらないので、行の数が減ったあとも高さが足りない場合がある。
- 回答エリアの高さを、札の数に合わせて変える案。D-0023 の、高さを固定する決定に反する。

## 根拠

- 同じ割合で縮めると、1行に入る札が増えて行の数も減る。札の高さと行の数の両方が減るので、少し縮めるだけで高さが足りるようになる。
- 下限の 0.6 では、文字の大きさは 10.8 になる。

## 影響
