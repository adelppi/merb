# D-0028 札の入る位置は、指に最も近い札の行と、指の x 座標で決める

- 日付: 2026-11-04
- 決めた人: adelppi が欲しい動きを伝え、AI が行の決め方を選んだ。PR で adelppi が確かめる
- 関係する Issue と PR: #63
- 解決した未解決の項目: なし
- 置き換える記録: [D-0023](D-0023-drag-rework.md) のうち、「上の行の札と、同じ行で中心が指より左にある札の数を、位置の番号にする」の、同じ行の判定

## 背景

札が一行に並んでいるとき、指の y 座標がその行から外れると、落とす候補が指の x 座標に合わせて動かないと、adelppi から指摘があった。これまでの判定では、指が札の行より下にあると札をすべて前にある札として数えるので、入る位置は x 座標によらず末尾になっていた。指が行より上にあると、札を1枚も数えないので先頭になっていた。

## 決定

- 回答エリアの札の行のうち、y 座標が指に最も近い行を、指のある行とする。
- 指のある行より上の行の札と、指のある行で中心が指より左にある札の数を、入る位置の番号にする。
- 行を選ぶときは、ドラッグしている札がいる行も候補に入れる。この行に札がほかになければ、これまでどおり、その行より上の札の数が位置の番号になる。
- 札置き場へ戻すかどうかは、これまでどおり、指が回答エリアの中にあるかどうかで決める。

## ほかの選択肢

- ドラッグしている札を行の候補に入れない案。札が1枚だけの最後の行にいるとき、指のある行が上の行に変わる。札を上の行の途中へ入れると別の札が次の行へ押し出され、また行が変わるので、指を動かすたびに並びが行き来する。

## 根拠

- 指が行から外れても、札の x 座標と比べられるので、一行のときに x 座標で入る位置が動く。
- 行が2つ以上あるときも、行の間の隙間に指があれば、近い行で決まる。
