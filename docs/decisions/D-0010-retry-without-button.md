# D-0010 間違えたあと、ボタンを押さずに解き直す

- 日付: 2026-11-03
- 決めた人: adelppi
- 関係する Issue と PR: #23
- 解決した未解決の項目: OQ-012
- 置き換える記録: D-0007 のうち「もう一度解く」で解き直す決定と、D-0001 の「やること」のうち間違えたときの1行

## 背景

[D-0007](D-0007-quiz-screen.md) では、間違えたときに「もう一度解く」を押すと札を運べる状態に戻す形にした。この形では、間違えるたびにボタンを押さないと札を動かせず、手間がかかる。そこで、ボタンを押さずに解き直せる形に変え、`vision.md` の「やること」の「間違えたときは、もう一度解くか、答えを見るかを選べる。」も書き換えることにした。開発者はこの書き換えに合意している。

ボタンを押さずに解き直せるようにすると、続けて不正解になったときに「不正解」の表示が変わらず、答え合わせをしたことが分からない。また、札を動かしたときに「不正解」の表示を残すかどうかも決める必要があった。

## 決定

開発者が決めたこと。

- 不正解のあとも、回答エリアの札を並べたまま、ボタンを押さずに札を運べる。そのまま「答え合わせ」をし直せる。
- 「もう一度解く」のボタンはなくす。「答えを見る」のボタンは残す。不正解のときに「次の問題」のボタンは出さない。
- 答え合わせのたびに「不正解」を出し直す。
- 間違えた回数は数えず、見せない。
- `vision.md` の「やること」の1行を「間違えたときは、ボタンを押さずにそのまま札を並べ直して解き直すか、答えを見るかを選べる。」に書き換える。

OQ-012 で推奨案を選んで決めたこと。

- 間違えたあとに札を運んで回答エリアの並びが変わったら、「不正解」の表示を消す。「答えを見る」のボタンは、次の問題を出すまで出したままにする。
- 「不正解」を出し直すときは、0.3 秒ほど左右に小さく揺らす。
- 利用者が動きを減らす設定（`prefers-reduced-motion: reduce`）にしているときは、揺らさずに、0.3 秒ほどかけて薄い色から元の色に戻して出す。

詳しい振る舞いは [1問を解く出題の画面](../specs/quiz.md) の「答え合わせ」の節に書いた。

## ほかの選択肢

- 札を動かしても、次に答え合わせをするまで「不正解」を出したままにする案。並べ直したあとの並びが不正解だと読めてしまうので採らなかった。
- 札を動かしたら「答えを見る」のボタンも消す案。答えを見るには、もう一度間違える必要が出るので採らなかった。
- 「不正解」をいったん消してから出し直す案。短い時間で消して出すと見落としやすく、長くすると操作を待たせるので採らなかった。
- 「不正解」の色を一瞬変える案。色だけの変化は見分けにくい人がいるので採らなかった。
- 動きを減らす設定のときは何もしない案。続けて不正解になったときに、答え合わせをしたことが分からなくなるので採らなかった。

## 根拠

- 札を運んだら「不正解」を消すと、出ている結果がいつも今の並びの結果になる。
- 揺らす動きは位置だけが小さく変わり、文言と色は変わらないので、画面がシンプルなまま、答え合わせをしたことが分かる。
- 薄い色から戻す動きは場所を動かさないので、動きを減らす設定の人にも出し直したことを示せる。

## 影響

- `docs/vision.md` の「やること」の1行を書き換えた。
- `docs/specs/quiz.md` の「目的」「札を運ぶ」「答え合わせ」と受け入れ条件を書き換えた。
- `open-questions.md` に OQ-012 を起票し、解決済みにした。
- 出題の進行の reducer、出題の画面、文言のファイルから「もう一度解く」をなくした。
