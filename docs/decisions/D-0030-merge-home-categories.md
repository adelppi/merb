# D-0030 ホームと分類を選ぶ画面をまとめ、選んだ分類を端末に保存する

- 日付: 2026-11-04
- 決めた人: adelppi（Issue #70 の依頼）。依頼に書かれていない細部は Claude Code が決めた。adelppi が PR で確かめる
- 関係する Issue と PR: #70
- 解決した未解決の項目: なし
- 置き換える記録: D-0008 のうち、選んだ分類を保存しない点、「すべての分類から出す」を置く点、トップページに分類の選択肢を置かない点。D-0020 のうち、分類を選ぶ画面のルートを `/categories` にする点、「すべての分類から出す」を置く点、選んだ分類を端末に保存しない点

## 背景

adelppi が Issue #70 で、次のことを依頼した。

- 出題の画面以外のホームと分類を選ぶ画面を、1つの画面にまとめる。
- 「すべての分類から出す」のボタンをなくし、一覧のところに「すべて選択」のボタンを付ける。
- 最後に選んだ分類を保存し、次に開いたときに選んだ状態で出す。
- 画面の右上に設定のボタンを置く。
- ボタンに SF Symbols のアイコンを付ける。一覧の行と札には付けない。
- 部品と形は、Apple の Human Interface Guidelines の Components を参考にする。

D-0008 では、選んだ分類の保存が `vision.md` の「やらないこと」の「学習の記録の保存」に当たるかどうかを決めきれず、保存しないことにしていた。

## 決定

- 分類を選ぶ画面をホーム（`/`）にまとめ、`/categories` のルートをなくす。大見出しは「merb」のままにする。
- 下のボタンは、「選んだ分類で始める」と「間違えた問題」の2つにする。「問題を解く」と「すべての分類から出す」はなくす。
- 一覧の見出しの行の右端に、「すべて選択」のボタンを置く。問題がある分類をすべて選んでいるときは、同じ位置のボタンを「すべて解除」に変える。
- 「すべて選択」は、問題が1問もない分類を選ばない。
- クエリのない `/quiz` は、これまでどおりすべての分類から出す。画面からは開かないが、Maestro のフローが使う。
- 選んだ分類は、選択を変えるたびに AsyncStorage のキー `merb.categories` に、分類の id の JSON の配列で保存する。
- 保存を読むときは、分類の id でないものと、問題が1問もない分類を除く。保存がないとき、読めないときは、どの分類も選んでいない状態にする。
- 選んだ分類の保存は、「やらないこと」の「学習の記録の保存」の例外にして `vision.md` に書く。
- ボタンのアイコンは次のとおりにする。

| ボタン | SF Symbols |
|---|---|
| 選んだ分類で始める | `play.fill` |
| 間違えた問題 | `arrow.counterclockwise` |
| すべて選択 | `checkmark.circle` |
| すべて解除 | `xmark.circle` |
| 設定 | `gearshape` |
| 答え合わせ | `checkmark` |
| 答えを見る | `eye` |
| 次の問題 | `arrow.right` |

## ほかの選択肢

- 「すべて選択」を押したあとも同じ文言のままにする案。すべて外す操作に、行を1つずつタップする手間がかかるので採らなかった。
- 「すべて選択」をヘッダーの左上に置く案。依頼が「リストのところ」なので採らなかった。
- 分類を、出題を始めたときにだけ保存する案。選んだだけでアプリを閉じると選択が消えるので採らなかった。
- 初めて開いたときに、すべての分類を選んだ状態にする案。これまでの「どの分類も選んでいない状態」を変える依頼はないので採らなかった。

## 根拠

- 選んだ分類は、次の出題の範囲の設定で、解いた結果を残すものではない。そのため、`vision.md` の「進捗の管理」には当たらない。
- Human Interface Guidelines の Buttons に、もっとも選ばれやすい操作には目立つ形のボタンを使うこと、押した状態を出すこと、周りに十分な余白を取ることがある。「選んだ分類で始める」を目立つ形にし、「間違えた問題」は控えめな形のままにする。「すべて選択」には押した状態と、高さ 44 のタップ領域を付ける。
- 同じ資料に、よく知られた操作にはよく知られたアイコンを結び付けることがある。Lists and tables に、一覧の項目を選んだときに応答を返すことがある。行の右端のチェックは、これまでどおりにする。
