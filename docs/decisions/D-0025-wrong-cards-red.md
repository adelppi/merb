# D-0025 不正解のとき、最も近い読み方と比べて、間違った札だけを赤で出す

- 日付: 2026-11-04
- 決めた人: adelppi（赤で出すこと。比べ方は推奨を選んだ）
- 関係する Issue と PR: #58
- 解決した未解決の項目: なし（OQ-020 の決定を置き換える）
- 置き換える記録: D-0018 のうち、OQ-020 の「不正解のとき、すべての札を同じ色で出す」。D-0018 のほかの項目は変えない

## 背景

[D-0018](D-0018-design-open-questions.md) で、不正解のとき回答エリアの札を位置ごとに緑と赤で分けないと決めた。理由は、判定が札ごとの結果を返す必要があり、読み方が複数ある問題でどの読み方と比べるかも決める必要があったことだった。adelppi が、間違った札だけを赤で出したいと求めたので、この2点を決める。

## 決定

- 不正解のとき、回答エリアの札のうち、間違っている札だけを赤で出す。合っている札は藍のままにする。緑は使わない。
- 並べた札を、`answers` の読み方のうち、位置ごとの違いが最も少ないものと比べる。違いは、同じ位置で文字列が違う札の数に、並べた札の数と読み方の札の数の差を足して数える。違いが同じ読み方が複数あれば、`answers` の先のものと比べる。
- 比べた読み方と、同じ位置で文字列が同じ札は藍、違う札と、読み方の札の数より後ろに並んだ札は赤にする。
- 赤にするのは、不正解の表示が出ているあいだだけにする。札を運んで並びが変わり、「不正解」の表示が消えたら、赤も消す。

## ほかの選択肢

- 合っている札を緑、違う札を赤にする案（デザイン 2b の形）。正解のときの緑と同じ色になり、間違いだけを見たい依頼に合わないので採らなかった。
- どの読み方にも使わない札だけを赤にする案。順番の間違いが分からないので採らなかった。

## 根拠

- 位置ごとの比較は、判定の「長さも順番も同じ」と同じ基準で、どこが違うかを示せる。
- 最も近い読み方と比べれば、複数の読み方がある問題でも、利用者が目指していた読み方に近い比べ方になる。
