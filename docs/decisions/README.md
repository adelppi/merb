# 決定の記録

決めたことの理由、背景、ほかの選択肢、根拠を残す。あとから「なぜこうなっているのか」を確かめるときに読む。

## 決まり

- 記録は追記だけにする。一度書いた記録のファイルは消さず、本文も書き換えない。
- 決定を変えるときは、新しい記録を書き、「置き換える記録」に古い記録の番号を書く。古い記録には、末尾に「D-0000 で置き換えた」の1行だけを足してよい。
- 誤字は直してよい。意味が変わる直しはしない。

## 書き方

- 1つの決定に1つのファイルを作る。ファイル名は `D-<4桁の連番>-<短い英語の名前>.md` にする（例: `D-0002-realtime-transport.md`）。
- 新しく作るときは `_template.md` を写す。
- 番号は、すでにある最大の番号の次にする。別の PR と番号がぶつかったら、あとからマージする側が番号を付け直す。
- 未解決の項目を解決した決定なら、`open-questions.md` のその項目からこの記録へリンクする。
