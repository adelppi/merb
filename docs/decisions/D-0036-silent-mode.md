# D-0036 消音モードでは読み方の音声を鳴らさない

- 日付: 2026-11-06
- 決めた人: adelppi（Issue #92）
- 関係する Issue と PR: #92
- 解決した未解決の項目: OQ-023
- 置き換える記録: なし

## 背景

`expo-speech` の資料に、iPhone が消音モードのときは音が出ないとある。消音モードでも鳴らすかどうかを決める必要があった。

## 決定

消音モードでは読み方の音声を鳴らさない。音が要るときは、利用者が消音モードを切る。`expo-audio` は入れない。

## ほかの選択肢

- `expo-audio` を入れて鳴らす案。`expo-audio` には録音のコードも入るので、マイクの使用目的の文言が要るかもしれない。背景再生の設定も外す必要があるので採らなかった。

## 根拠

adelppi が OQ-023 の選択肢から (a) を選んだ。

## 影響

- `docs/specs/quiz.md` の「読み方を聞く」を書き換えた。
