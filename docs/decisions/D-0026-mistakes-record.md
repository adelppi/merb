# D-0026 間違えた問題の id だけを端末に保存し、あとで再挑戦できるようにする

- 日付: 2026-11-04
- 決めた人: adelppi（記録することと、`vision.md` を書き換えて許すこと、入口と消える条件。保存先と形は Claude Code が決め、PR で確かめる）
- 関係する Issue と PR: #59
- 解決した未解決の項目: なし
- 置き換える記録: なし。D-0001 の「やらないこと」のうち「学習の記録の保存と、端末をまたいだ同期」に、この決定の例外を設ける

## 背景

`vision.md` の「やらないこと」に「学習の記録の保存と、端末をまたいだ同期」と「進捗の管理」がある。adelppi が、間違えた問題を記録して、あとで再挑戦できるようにしたいと求めた。この Issue を受けるには、`vision.md` を書き換える合意が要る（`vision.md` の「やらないこと」の前置き）。

## 決定

- `vision.md` の「やらないこと」のうち「学習の記録の保存」に、例外を1つ設ける。端末の中に、間違えた問題の id だけを保存してよい。
- 記録するのは、答え合わせで不正解になった問題の id だけにする。間違えた回数、日時、正解率、正解した問題は記録しない。端末をまたいだ同期、アカウントは引き続きやらない。「進捗の管理」も引き続きやらない。
- 保存先は `@react-native-async-storage/async-storage`、キーは `merb.mistakes`、値は問題の id の JSON の配列にする（言語の保存と同じ道具。[D-0019](D-0019-i18n-and-locale-storage.md)）。
- ホームに「間違えた問題」のボタンを足す。押すと、記録した問題だけで出題を始める。記録が空のときは押せない。
- 再挑戦で、一度も間違えずに正解した問題は、記録から消す。
- 記録の手動での削除は作らない。

## ほかの選択肢

- 分類を選ぶ画面の選択肢にする案。分類の選択は問題の「範囲」で、記録は別の入口にしたほうが画面がシンプルなので採らなかった。
- 正解したら、通常の出題でも記録から消す案。再挑戦のための記録なので、消える条件は再挑戦に絞った。
- 間違えた回数や日時も持つ案。「進捗の管理」に当たるので採らなかった。

## 根拠

- id だけの記録は、アプリ内の問題の JSON から問題を引くので、保存する量が小さく、問題の中身が変わっても壊れない。
- 保存先を言語と同じにすると、新しい依存が要らない。

## 影響

- `docs/vision.md` の「やること」と「やらないこと」を書き換える。
- `docs/specs/mistakes.md` を新しく作り、`docs/specs/quiz.md` と `docs/specs/README.md` を書き換える。
- `src/mistakes/` を足し、ホームと出題の画面を変える。`AGENTS.md` の置き場の表に `src/mistakes/` を足す。
