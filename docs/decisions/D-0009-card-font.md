# D-0009 札の文字の書体

- 日付: 2026-11-03
- 決めた人: adelppi。英単語の `a` の扱いと読み方の書体は、AI が推奨した案で決め、adelppi が PR で確かめる
- 関係する Issue と PR: #22
- 解決した未解決の項目: OQ-011
- 置き換える記録: なし

## 背景

札の文字を数式と同じ KaTeX の書体で出し、どの札が数式のどの文字に当たるかを見分けやすくしたい。そのために、斜体で出す札の見分け方と、答えを見せるときの読み方の書体を決める必要があった。

問題の JSON には、札が数式の文字か英単語かを書くキーがない。`content/questions/` には、数式の文字の `a`（`a plus b` など）と、英単語の `a`（`a half`、`a hundred`、`with a remainder of` など）の両方がある。1つの問題の中で両方を使う問題はない。まぎらわしい札にも英字1文字の札があり、`\Delta x` や `\partial` の問題には、数式に出てこない `d` を入れている。

## 決定

- 札の文字は、回答エリア、札置き場、ドラッグ中の札のどれでも、KaTeX の書体で出す。
- 札の文字列が英字1文字のときは、数式の中の文字と同じ斜体で出す。英単語の `a` も斜体で出す。
- ほかの札は、KaTeX の立体で出す。
- 判定と札のボタンの名前は、札の文字列のままにする。
- 答えを見せるときの読み方（「ほかの読み方」と「答え」）は、札の書体にせず、画面の文言と同じ書体で出す。
- 画面の文言（ボタン、見出し）の書体は変えない。

詳しい振る舞いは [1問を解く出題の画面](../specs/quiz.md) の「画面」に書いた。

## ほかの選択肢

- 札の文字が問題の `latex` に文字として出てくるときだけ斜体にする案。英単語の `a` を立体で出せるが、数式に出てこない英字1文字のまぎらわしい札（`\Delta x` の問題の `d` など）が立体になり、まぎらわしい札だと書体で分かってしまうので採らなかった。
- 英単語の `a` だけを立体にする案。数式の文字の `a` も立体になり、英単語の `a` より多く使っているので採らなかった。
- 問題の JSON に、斜体にする札を書くキーを足す案。Issue #22 の範囲外の「問題の JSON の形を変えること」に当たるので採らなかった。
- 読み方も KaTeX の書体にし、英字1文字の語を斜体にする案。読み方は `text` のカンマを含めて文として見せるもので、札と数式の文字を見比べるためのものではないので採らなかった。

## 根拠

- 英字1文字の札をすべて斜体にすれば、問題の JSON の形を変えずに済み、まぎらわしい札も正解の札と同じ見た目になる。
- 英単語の `a` は、数と分数の読み方などに出てくる。斜体の `a` が英単語の `a` を指すこともあるが、1つの問題の中で数式の文字の `a` と取り違えることはない。

## 影響

- `docs/specs/quiz.md` の「画面」に札と読み方の書体を書き足し、受け入れ条件を1つ足した。
- `open-questions.md` に OQ-011 を起票し、解決済みにした。
