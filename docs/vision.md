# 要求と思想

merb が誰のためのアプリで、何をして何をしないのかを書く。機能を足すかどうか迷ったときは、この文書に照らして決める。

この文書を書き換えるときは、理由を `decisions/` に残す。まだ決まっていない項目は「未記入」とし、`open-questions.md` の項目へリンクする。

名前の merb は、math と、ラテン語で「言葉」を意味する verbum を合わせたもの。

## 誰のためのアプリか

日本語で数学教育を受けてきた数学の学習者のうち、数学を英語でも表現できるようになりたい人。（[D-0001](decisions/D-0001-vision.md)）

## 解決したいこと

日本語で数学教育を受けると、数式をはじめとする数学の表現を、たいてい日本語でしか言えない。merb は、数学の学習を進めながら英語での数学の表現も身につけたい、という学習者の思いに応える。（[D-0001](decisions/D-0001-vision.md)）

## 責務

このアプリが受け持つ範囲を書く。

- 数式の英語での読み方を、問題を解きながら学べるようにする。
- 出す問題の読み方が正しいことに責任を持つ。そのため、出す問題はあらかじめ作り、中身を確かめたものに限る。（[D-0002](decisions/D-0002-question-source.md)）

## やること

- 数式の英語での読み方を問う、並び替えの問題を出す。
  - 画面に数式を LaTeX で描いて出し、その下に読み方の英語を区切った札をばらばらに並べる。札は単語で区切るのを基本とし、長い式ではある程度まとめて句で区切る。
  - 利用者は、札をタップかドラッグで回答エリアに運び、回答エリアの中でも並べ替えられる。
  - 札には、正解に使わないまぎらわしい札を混ぜてよい。
  - 読み方が複数ある数式では、複数の読み方を正解として認める。
  - 間違えたときは、もう一度解くか、答えを見るかを選べる。
- 出題の範囲は、観点シートの分類から選ぶ。分類は複数選べる。どの分類からも出すランダムの出題もできる。
- 出題は区切らずに続け、利用者はやめたいときにやめられる。
- 問題は、観点シートをもとに LLM で作り、中身を確かめた JSON としてリポジトリに入れる。アプリはその JSON から出題する。（[D-0002](decisions/D-0002-question-source.md)）
- 画面の文言は日本語と英語に対応する。
- スマートフォンでも使える。

## やらないこと

このアプリが面倒をみないことを書く。ここに書いたことを求める Issue は、この文書を書き換える合意がない限り受けない。

- アカウント
- 学習の記録の保存と、端末をまたいだ同期
- 進捗の管理
- ゲーム性
- サーバーで LLM を呼び、利用中に問題を作ること（[D-0002](decisions/D-0002-question-source.md)）

## 判断の基準

機能の取捨や設計で迷ったときに優先する考え方を、優先する順に書く。（[D-0001](decisions/D-0001-vision.md)）

1. 出す問題の読み方が正しいこと。
2. 画面がシンプルであること。キャッチフレーズ、説明文、AI らしい飾りの文言は入れない。ただし、出題の画面には、何をすればよいかを伝える問題文を例外として出す。（[D-0011](decisions/D-0011-question-prompt.md)）
3. スマートフォンでも操作しやすいこと。
