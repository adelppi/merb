# 未解決の項目

まだ決まっていない要件や疑問を書きためる。ドキュメントやコードを書いている途中で決められないことが出たら、その場で追記する。

## 書き方

- 番号は `OQ-` に3桁の連番を付ける。一度付けた番号は使い回さない。
- 新しい項目は「未解決」の節の末尾に足す。
- 解決したら、項目を「解決済み」の節へ移し、状態を「解決」にして、決定（`decisions/`）へのリンクを書く。
- 決めないことにした項目は、状態を「取り下げ」にして理由を1行書き、「解決済み」の節へ移す。
- 項目は消さない。

項目の形は次のとおり。

```markdown
### OQ-000

- 問い: （何が決まっていないか）
- 状態: 未解決 / 解決 / 取り下げ
- 起票: YYYY-MM-DD、Issue #番号（あれば）
- 影響: （決まらないと進められないもの。仕様のファイルや Issue）
- 選択肢: （分かっていれば）
- 決定: （解決したら decisions/ へのリンク）
```

### OQ-011

- 問い: 札の文字を KaTeX の書体で出すとき、数式の斜体で出す1文字の札をどう見分けるか。英単語の `a` のように、英字1文字と同じ文字列の札をどう扱うか。答えを見せるとき（正解のときの「ほかの読み方」と「答えを見る」）の読み方も、札と同じ書体にするか。
- 状態: 解決
- 起票: 2026-11-03、Issue #22
- 影響: `docs/specs/quiz.md` の「画面」
- 選択肢:
  - 1文字の札の見分け方: (A) 英字1文字の札をすべて斜体にする。英単語の `a` も斜体になる。(B) 札の文字が問題の `latex` に文字として出てくるときだけ斜体にする。(C) 英単語の `a` だけを立体にする。(D) 問題の JSON に、斜体にする札を書くキーを足す。推奨は (A)。
  - 読み方の書体: (A) 変えず、画面の文言と同じ書体にする。(B) KaTeX の書体にし、英字1文字の語を斜体にする。推奨は (A)。
- 決定: [D-0009](decisions/D-0009-card-font.md)
